# Velocity deal

A transactional or SMB deal one rep runs. Get a reply from the champion, show the fit, close. Short emails, a five-day quiet window, and no account map.

A Canon recipe (`@fsgtm/velocity-deal` v1.0.0) by fsgtm. Install it in Canon under Settings → Workspace → Recipes → Install from GitHub, with the source `github:<owner>/<repo>[/<path>]@v1.0.0`.

## What it asks for

- Reads: deal, contact, account, observations, icps
- Fills: deal.page
- Model: prompts run on the rep's own model plan
- Sources: web_search, read_site

Its code (`dist/recipe.js`, bundle 71d344038c52f51461de00e64598aa6a) runs only in Canon's recipe runtime: an isolate with no network, no secrets and a CPU limit. It returns data; every write goes through Canon's own gates.

## Evals

- **Clean email passes.** A four-sentence, 34-word first touch passes every draft check.
- **70 words is too long.** A 70-word email fails "Reads without scrolling on a phone" at the 60-word cap.
- **Pitch fails.** "Our platform" fails "Shares a view, doesn't pitch".
- **Draft prompt names the word cap.** The email draft prompt asks for at most the configured number of words.
- **A replied deal at 40% is closing.** Once the buyer has replied, a deal at the close probability moves to Close.
- **No champion is flagged.** A deal whose only person isn't the champion gets the no-champion flag.
